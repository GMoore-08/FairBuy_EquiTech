# FairBuy — EquiTech

Landing page informativa para FairBuy, un sistema de evaluación de compras para plataformas de comercio electrónico.

## Tecnologías

- HTML5
- CSS3
- JavaScript (vanilla)

No requiere dependencias, compilación ni servidor backend.

## Estructura

```
.
├── index.html
├── css/
│   └── styles.css
├── js/
│   └── main.js
├── assets/
│   └── images/
└── README.md
```

## Ejecutar localmente

Abre `index.html` en un navegador. Para una experiencia más consistente, puedes utilizar la extensión Live Server de Visual Studio Code.

## Publicar con GitHub Pages

1. Abre el repositorio en GitHub.
2. Entra en **Settings → Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**.
4. Elige la rama `main` y la carpeta `/(root)`.
5. Pulsa **Save**. Cuando termine el despliegue, GitHub mostrará la URL pública del sitio en esa misma sección.

El archivo `index.html` se encuentra en la raíz del repositorio para que GitHub Pages pueda servirlo directamente.

## Antes de publicar

- Sustituye el correo de ejemplo del enlace de contacto por una dirección oficial de EquiTech.
- Revisa el contenido y confirma que las funcionalidades descritas coinciden con la versión que el equipo realmente implementará.
- Las fuentes tipográficas se cargan desde Google Fonts; si no hay conexión, se utilizarán las fuentes alternativas del sistema.

## Alcance

Esta es una landing page estática de presentación comercial. No implementa autenticación, pagos, procesamiento real de transacciones ni conexión con el motor backend de FairBuy.
